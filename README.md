# Simple Pac-Man

A small Pac-Man-inspired arcade game created in **Processing** as an early programming project. The game runs on a single horizontal track and includes pellets, scoring, a moving ghost, a temporary fruit power-up and a game-over state.

## Features

- Pac-Man moves continuously along the track
- Pressing the spacebar reverses Pac-Man's direction
- Pellets increase the score when collected
- Pellets respawn after a full set is cleared
- A ghost moves independently and changes direction at random
- Contact with the ghost triggers a game-over state
- Collecting a fruit grants temporary invulnerability

## Built With

- [Processing](https://processing.org/)
- Java-based Processing syntax

## How to Run

1. Install Processing.
2. Clone or download this repository.
3. Open `pman/pman.pde` in the Processing IDE.
4. Press **Run**.

## Controls

| Key | Action |
| --- | --- |
| Spacebar | Reverse Pac-Man's direction |
